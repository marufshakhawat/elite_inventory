
# Elite Inventory

**Instant. Premium. Yours.**  
A world-class marketplace for elite digital assets and professional license keys.

## 🚀 Tech Stack
- **Frontend:** React 19, Tailwind CSS, Lucide React
- **Routing:** React Router DOM (HashRouter)
- **State Management:** React Context API
- **Icons:** Lucide React
- **Build Tool:** ESM.sh (Module Imports)

## ✨ Features
- **Modern UI:** Professional Slate/White theme with glassmorphism effects.
- **Product Management:** Full Shop with categories (Writing Tools, VPN, Dev Tools, etc.).
- **Shopping Cart:** Robust cart system with local storage persistence.
- **Secure Manual Checkout:** Integrated manual MFS (bKash/Nagad) payment flow with screenshot upload.
- **Admin Dashboard:** Manage products (Add/Edit/Delete) and verify manual orders.
- **User Dashboard:** Track order history and access purchased license keys.
- **Wishlist:** Save assets for future purchase.
- **Responsive:** Optimized for Mobile, Tablet, and Desktop.
- **SEO Optimized:** Clean semantic HTML structure.

## 🛠️ Setup Instructions
1. This project is a standalone React application using ES modules.
2. Ensure you have a modern web browser.
3. Serve the root directory using any local web server (e.g., `npx serve .` or Live Server in VS Code).
4. The application uses `localStorage` for data persistence in the browser.

## 📁 Project Structure
- `App.tsx`: Main routing and layout wrapper.
- `store/`: Context API for global state management.
- `components/`: Reusable UI components (Navbar, Footer, ProductCard).
- `pages/`: Individual route components.
- `utils/`: Mock data and utility functions.
- `types.ts`: TypeScript interfaces.
